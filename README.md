
# Portfolio & Stageblog (React)

## Starten
```bash
npm install
npm run dev
```

## Waar invullen?
- `src/components/Layout.tsx`: LinkedIn/CV link
- `src/pages/About.tsx`: jouw gegevens + foto
- `src/data/posts.ts`: blogposts, tags, afbeeldingen

## Afbeeldingen
Zet je eigen foto in `public/images/profile.jpg`.
